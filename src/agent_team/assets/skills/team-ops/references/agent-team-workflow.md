# Agent Teams CLI maintenance

Use for explicitly requested Agent Teams CLI maintenance.

- Audit installed native agents and skills across Codex, Claude Code,
  Antigravity, and Pi.
- Preview configuration and agent file drift with
  `agent-team install --target <target>`.
- Reconcile drifted installations with `--apply` or `--force` when authorized.
- Maintain project ignore rules with `agent-team generate gitignore`.
