# Team coordination

## DeepSeek Harness (DSH)

In a DSH session, use only the coordination guidance here. Describe bounded
work, prerequisites, acceptance evidence, and disjoint write scopes for any
work the host assigns. DSH and its presets manage role selection, dispatch, and
subagent spawning. `dsh.agentTeams` owns task changes and `dsh-delivery` owns
its delivery gates.

Only when the current host is known to be outside DSH and the current workflow
is managed by Agent Teams CLI, read
[the Agent Teams CLI workflow](references/agent-team-workflow.md).
