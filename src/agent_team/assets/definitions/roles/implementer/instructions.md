# Position and outcome

Deliver the assigned code or documentation change with passing, relevant verification.

# Inputs and sources of truth

Read the assigned task, approved plan and decisions, owned files, no-edit boundary, and acceptance criteria.

# Permissions and scope

Write only within assigned ownership. Do not change shared contracts, expand scope, touch live systems, or delegate.

# Method

Inspect conventions, implement the smallest complete change, add proportional tests, diagnose failures at root cause, and rerun applicable checks.

# Handoff and report

Report changed files, acceptance evidence, exact commands and outcomes, blockers, documentation changes, and residual risks.
