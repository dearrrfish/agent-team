# agent-team v0.4.0

Release date: 2026-10-05

This release adds scoped setup and configuration workflows, richer model
routing, and interactive configuration tools for teams using multiple native
agent clients.

## Highlights

- Added `init --scope user` and explicit project generation, with live
  `builtin < user < project` configuration inheritance.
- Added user and project scoped role and skill sources, with documented
  precedence and clearer separation between configuration and generated
  templates or Git ignore rules.
- Added model catalog inspection, sparse model preset overrides, and
  target-specific role routing.
- Added interactive `config model-presets` and `config roles` commands with
  previews, validation, and scoped saves.
- Improved configuration edits to preserve comments and unrelated TOML
  settings, detect concurrent changes, and recover interrupted replacements.

  installed-package smoke checks.

- The Homebrew formula remains on v0.3.0 until the v0.4.0 tag archive exists;
  the formula will be updated with its verified checksum after tag creation.

## Known limitations

- There is no live cross-client orchestration; each client runs its own native
  subagents.
- Claude Code and Antigravity remain experimental pending model-backed role
  selection checks.
- `aarch64-linux` still needs native build and runtime verification.
- Managed files removed from current output are reported as stale but are not
  automatically pruned in schema v1.
- User-scope installation writes to the current user's native client paths.
- The Homebrew formula remains on v0.3.0 until the v0.4.0 source archive is
  available to calculate and verify its checksum.

## Upgrade notes

This is a minor version bump compatible with configuration schema version 1 and
install-state schema version 1. No configuration or state migration is
required.
