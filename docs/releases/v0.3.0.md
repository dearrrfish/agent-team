# agent-team v0.3.0

Release date: 2026-09-25

This release introduces an enhanced `init` command that automatically seeds
common workflow prompt templates and maintains `.gitignore` hygiene, alongside
an official Homebrew formula for native installation on macOS.

## Highlights

- Enhanced `agent-team init` command to automatically populate common workflow
  prompt templates into `.agent-team/templates/prompts/` (`plan.md`,
  `coordinate.md`, `review.md`, and `discovery.md`), matching the documented
  workflow guidance.
- Enhanced `agent-team init` to upsert canonical `agent-team` ignore entries into
  `.gitignore` (`.worktrees/`, `.agent-team/runs/`, `.agent-team/backups/`, and
  `.agent-team/install-state.json`) without duplicating existing rules.
- Ensured `agent-team init` is idempotent, preserving existing `.agent-team/team.toml`
  configurations when re-run on established projects.
- Added official Homebrew formula (`Formula/agent-team.rb`) enabling native
  installation on macOS via `brew install dearrrfish/agent-team/agent-team`.

## Installation

### Nix

Run directly from the canonical GitHub repository:

```console
nix run github:dearrrfish/agent-team/v0.3.0 -- --version
```

Or install it into a Nix profile:

```console
nix profile install github:dearrrfish/agent-team/v0.3.0
agent-team --version
```

### Homebrew (macOS)

Install using Homebrew:

```console
brew install dearrrfish/agent-team/agent-team
agent-team --version
```

### Source

Install from source with pip:

```console
pip install .
agent-team --version
```

## Verification

The core `nix flake check` gate builds the application, runs the Python unit
suite and Ruff, ShellChecks the release smoke script, validates the
documentation with Markdownlint, and exercises the installed binary through
initialization, validation, team-run creation, all-target render and apply,
repeat-apply idempotence, and doctor diagnostics.

The release has been built and verified on `x86_64-linux`. All declared aarch64
derivations evaluate successfully without building.

## Known limitations

- There is no live cross-client orchestration; every client runs its own native
  subagents.
- Claude Code and Antigravity remain experimental until their model-backed role
  selection checks are complete.
- `aarch64-linux` lacks native runtime evidence.
- Managed files that disappear from current output are reported as stale but are
  not automatically removed in schema v1.
- User-scope installation is global to the current user's native client paths.

## Upgrade notes

This is a minor version bump (`0.3.0`) compatible with configuration schema
version 1 and install-state schema version 1. No configuration file changes or
state migrations are required when upgrading from `v0.2.0` or `v0.1.0`. Existing
projects can re-run `agent-team init` to receive the workflow prompt templates
and missing `.gitignore` rules without altering their `team.toml`.
