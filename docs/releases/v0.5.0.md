# agent-team v0.5.0

Release date: 2026-11-02

This release introduces native opt-in support for the Pi agent platform, cross-client
session-bound hooks for Codex and Antigravity, compact context-compaction recovery,
and hierarchical configuration inheritance.

## Highlights

- **Pi platform opt-in support**:
  - Full native support for `pi` as an opt-in installation target (`--target pi`).
  - Zero-vendoring plugin discovery: validates existing ecosystem subagent runners
    (`pi-subagents`, `pi-agents-flow`) without modifying client settings.
  - Graduated preflight checks: hard installation blocks for missing subagent runners,
    and clear fallback warnings when sandboxing or worktree isolation is not present.
  - Dedicated isolated RPC validation harness (`tools/pi_validation.py`) for developers.
- **Cross-client hook lifecycle**:
  - Extends resume hooks to Codex and Antigravity with active session binding and
    automatic state reconciliation.
  - Adds `agent-team resume hooks --status --json` for programmatic integration.
  - Guarantees strict session isolation: hooks inject run context only for runs
    explicitly bound to the active session ID.
- **Compact recovery and configuration inheritance**:
  - Introduces bounded context-compaction recovery commands and evidence state inspection.
  - Supports live ancestor directory configuration inheritance (`builtin < user < ancestor < project`)
    without requiring explicit project initialization.
- **Workflow template improvements**:
  - Stock prompts incorporate anti-involution circuit breakers and human-first
    reporting standards.

Configuration and install-state schemas remain fully backward-compatible (schema version 1).
Existing projects do not require configuration migrations. Run `agent-team install --apply`
to update native agent definitions and workflow skills in your configured targets.
