# agent-team v0.6.0

Release date: 2026-11-11

This minor release introduces four new core workflow skills (`team-debug`,
`team-research`, `team-docs`, `team-ops`), converges workflow guidance and
anti-involution circuit breakers into native skills, normalizes template
directories to singular form, and updates the Homebrew formula.

## Highlights

- **Four new standard workflow skills**:
  - `team-debug`: Enforces reproduce-first diagnosis, evidence-based hypothesis
    testing, a hard 50% limit on test scaffolding volume, and regression
    verification against the original failure input.
  - `team-research`: Provides read-only / sandboxed codebase and factual
    discovery, strict demarcation of verified facts from inferences, and
    structured decision packs.
  - `team-docs`: Enforces contract change synchronization across docs and code,
    verifies runnable commands and examples in real environments, and maintains
    Architecture Decision Records (ADRs).
  - `team-ops`: Enforces Nix and flake integrity gates, drift and installation
    management, platform/CI verification, and workspace hygiene.
- **Workflow & templates architectural convergence**:
  - Converged all operational workflows, main-thread coordinator activation
    choices, anti-involution circuit breakers, and pragmatic review rules into
    native skills.
  - `agent-team generate templates` focuses exclusively on configuration and
    scaffolding examples (`profile/`, `role/`, `review/`), removing redundant
    stock prompt markdown files.
- **Singular directory normalization**:
  - Unified template directories into consistent singular names (`profile/`,
    `role/`, `review/`), eliminating duplicate plural directory generation
    (`profiles/`, `roles/`, `prompts/`).
- **Homebrew formula update**:
  - Updated `Formula/agent-team.rb` with verified release archive digests.
