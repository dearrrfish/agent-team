# agent-team v0.2.0

Release date: 2026-09-25

This release introduces local Git commit hash reporting for package versions,
updates default Codex model presets, refines Claude Code native agent
formatting, and establishes repository governance and macOS setup documentation.

## Highlights

- Package version reporting via `agent-team --version` now embeds the Git commit
  hash using PEP 440 local version identifier format (e.g.
  `agent-team 0.2.0+4110792`) when built via Nix, source packaging, or run
  within a git checkout.
- Updated default Codex model presets from older model identifiers to
  `gpt-6-sol` (for economy and balanced profiles) and `gpt-6-luna` (for quality
  profile).
- Aligned Claude Code native agent tool specifications with client formatting
  expectations.
- Added comprehensive macOS setup and usage documentation.
- Integrated repository governance baseline including GitHub Actions CI
  workflows, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, and `SECURITY.md`.
- Expanded `AGENTS.md` instructions for dogfooding native agent teams across
  tiers.

## Installation

Run directly from the canonical GitHub repository:

```console
nix run github:dearrrfish/agent-team/v0.2.0 -- --version
```

Or install it into a Nix profile:

```console
nix profile install github:dearrrfish/agent-team/v0.2.0
agent-team --version
```

Or install from source with pip:

```console
pip install .
agent-team --version
```

## Verification

The core `nix flake check` gate builds the application, runs the Python unit
suite and Ruff, ShellChecks the release smoke script, validates the
documentation with Markdownlint, and exercises the installed binary through
initialization, validation, team-run creation, all-target render and apply,
repeat-apply idempotence, and doctor diagnostics.

The release has been built and verified on `x86_64-linux`. All declared aarch64
derivations evaluate successfully without building.

## Known limitations

- There is no live cross-client orchestration; every client runs its own native
  subagents.
- Claude Code and Antigravity remain experimental until their model-backed role
  selection checks are complete.
- `aarch64-linux` lacks native runtime evidence.
- Managed files that disappear from current output are reported as stale but are
  not automatically removed in schema v1.
- User-scope installation is global to the current user's native client paths.

## Upgrade notes

This is a minor version bump (`0.2.0`) compatible with configuration schema
version 1 and install-state schema version 1. No configuration file changes or
state migrations are required when upgrading from `v0.1.0`.
