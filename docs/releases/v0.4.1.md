# agent-team v0.4.1

Release date: 2026-10-13

This patch clarifies native role instructions, coordinator responsibilities,
and evidence handoffs across planning, coordination, and review.

## Changes

- Clarified coordinator authority, report ownership, task-based tier selection,
  execution budgets, partial handoffs, and revision-bound evidence.
- Distinguished architecture proposals from independent design audits and
  aligned ops guidance with the existing project toolchain.
- Improved coordination and review guidance for coordinator writes, shared
  runtime resources, failed workers, and invalidated verification evidence.
- Fixed reviewer instructions and stock prompts to use the validator's
  `approved` verdict; read-only workers return reports for the coordinator
  to persist.

## Installation

```console
nix run github:dearrrfish/agent-team/v0.4.1 -- --version
```

## Native support and known limitations

- Codex native discovery and role selection are supported.
- Claude Code and Antigravity remain experimental pending complete
  authenticated model-backed native validation.
- `aarch64-linux` requires native build and runtime verification.
- Each client runs its own native subagents; live cross-client orchestration
  is not provided.
- Stale managed files are retained rather than automatically pruned.
